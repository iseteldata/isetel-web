ISETEL Guatemala - Sitio web estático

ARCHIVOS PRINCIPALES
- index.html: página de inicio
- nosotros.html: quiénes somos
- servicios.html: servicios y galería
- contacto.html: información de contacto y enlace para escribir por correo
- styles.css y main.js: estilos y menú adaptable
- img/: logotipo e imágenes del sitio

PUBLICACIÓN
Suba el contenido de esta carpeta al directorio público del hosting (por ejemplo public_html o www). No necesita PHP ni base de datos.

CONTACTO
La sección Contáctenos usa un enlace mailto a isetel.data@gmail.com. El visitante debe tener configurada una aplicación o servicio de correo. Esta versión no almacena mensajes ni los envía automáticamente desde el sitio.

IMPORTANTE
No se incluyen archivos PHP, credenciales SMTP, base de datos ni contraseñas.
